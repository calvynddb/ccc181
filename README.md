Mito is a queue management system for customers and staff at internet cafes such as Arena. Customers can check open Standard and VIP PC counts before heading over, join individually for one PC type with a nickname and optional phone number, and follow their ticket number, status, and people ahead remotely; a 10-minute hold lets them pause and return to their original place while staff call other ready customers. Staff use `/staff` to mark stations free or busy, classify or add PC stations, view Standard and VIP queues, manually assign a free PC of the matching type to the oldest waiting ticket, call that person, and mark them served or a no-show. When called, customers can see their five-minute response deadline. Mito does not detect station availability or assign PCs automatically. Staff routes currently have no login; staff authentication is deferred to Week 11 under [issue #4, Protect staff routes](https://github.com/calvynddb/ccc181/issues/4). To run a fresh clone on Windows, confirm `python -VV` reports Python 3.13.12 as pinned in `.python-version`, run `python -m venv .venv`, activate it with `./.venv/Scripts/Activate.ps1`, copy `.env.example` to `.env` and set a private random `SECRET_KEY` and PostgreSQL password, using the same password in `POSTGRES_PASSWORD` and `DATABASE_URL`, run `python -m pip install -r requirements.txt`, start PostgreSQL with `docker compose up -d`, create the schema with `flask --app app db upgrade`, add starting data with `flask --app app seed`, and start Mito with `flask --app app run --debug` at http://127.0.0.1:5000. Week 4 requirements are listed in [docs/requirements.md](docs/requirements.md).
