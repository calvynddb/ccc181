Mito is a queue management system for customers and staff at internet cafes such as Arena. Customers can check the open-PC count before heading over, join individually for one PC with a nickname and optional phone number, and follow their ticket number, status, and people ahead remotely; a 10-minute hold lets them pause and return to their original place while staff call other ready customers. Staff use `/staff` to mark stations free or busy, add PC stations, view the queue in order, manually assign a specific free PC to the oldest waiting ticket, call that person, and mark them served or a no-show. When called, customers can see their five-minute response deadline. Mito does not detect station availability or assign PCs automatically. Staff routes currently have no login; staff authentication is deferred to Week 11 under [issue #4, Protect staff routes](https://github.com/calvynddb/ccc181/issues/4). Use stable Python 3.13.12 as pinned in `.python-version`; before creating `.venv`, confirm `python -VV` reports Python 3.13.12, then run `python -m venv .venv`, activate with `./.venv/Scripts/Activate.ps1`, install with `python -m pip install -r requirements.txt`, and start the app with `flask --app app run --debug`. Open Mito at http://127.0.0.1:5000. Week 4 requirements are listed in [docs/requirements.md](docs/requirements.md).
