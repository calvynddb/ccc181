Mito is a queue management system for customers and staff at internet cafes such as Arena. Customers can check the open-PC count before heading over, join individually for one PC with a nickname and optional phone number, and follow their ticket number, status, and people ahead remotely; a 10-minute hold lets them pause and return to their original place while staff call other ready customers. Staff use `/staff` to mark stations free or busy, view the queue in order, manually assign a specific free PC to the oldest waiting ticket, call that person, and mark them served or a no-show. Mito does not detect station availability or assign PCs automatically, and `/staff` currently has no login. Use stable Python 3.13.12 as pinned in `.python-version`; before creating `.venv`, confirm `python -VV` reports Python 3.13.12, then run `python -m venv .venv`, activate with `./.venv/Scripts/Activate.ps1`, install with `python -m pip install -r requirements.txt`, and start the app with `flask --app app run --debug`. Open Mito at http://127.0.0.1:5000.
