# Mito — Tibanga Internet Cafe Queue

Mito is a queue management system for Arena internet cafe in Tibanga. Customers check open PC availability, join individually for one PC using a nickname and optional phone number, and track their ticket remotely; staff manually tracks station availability and calls waiting customers. The staff dashboard at `/staff` is currently open without login. Use stable Python 3.13.12 as pinned in `.python-version` and as the VS Code workspace default. Before creating `.venv`, confirm `python -VV` reports Python 3.13.12; then run `python -m venv .venv`, activate it with `./.venv/Scripts/Activate.ps1`, install dependencies with `python -m pip install -r requirements.txt`, and start Mito with `flask --app app run --debug` at http://127.0.0.1:5000. The app rejects prerelease Python versions at startup with a clear error.
